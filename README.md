# Customer Buying Trends Prediction using Neural Network

This project is developed as a student mini project to analyze customer details and predict whether a customer will purchase a product or not using a Neural Network model.

---

## Objective

The main objective of this project is to study customer buying behavior based on factors like age and salary and predict purchasing decisions using machine learning techniques.

---

## Tools and Technologies Used

- Python
- Google Colab
- PySpark
- Machine Learning
- Neural Network
- Graphviz

---

## Dataset

A sample dataset is used in this project with the following attributes:

- Age
- Salary
- Purchased (0 = No, 1 = Yes)

---

## Methodology

1. Import required libraries  
2. Create sample customer dataset  
3. Convert data into feature vectors  
4. Split data into training and testing sets  
5. Train Neural Network model  
6. Predict customer purchase results  
7. Evaluate model accuracy  
8. Display neural network structure  

---

## Model Used

Multilayer Perceptron Classifier (Neural Network)

- Input Layer: 2 neurons  
- Hidden Layers: 4 and 3 neurons  
- Output Layer: 2 neurons  

---

## Output

The model predicts whether the customer will:

- Purchase the product  
- Not purchase the product  

It also shows prediction accuracy.
